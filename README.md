# Blog Platform with Comments

## Overview

A blogging platform developed as part of a Full Stack Development Internship. Users can create blog posts and interact through comments.

## Features

* User Registration
* User Login & Authentication
* Create Blog Posts
* Edit Blog Posts
* Delete Blog Posts
* Comment System
* RESTful APIs
* Database Integration

## Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB
